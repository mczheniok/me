# Resume — Yevhenii Shorobura

A bilingual (Ukrainian / English) developer resume, built as a bento-grid layout in the same visual language as [Shorado](https://shorado.com.ua) — cream background, amber / green / blue accents, `Bricolage Grotesque` for headings and `JetBrains Mono` for code-style elements.

---

## ✨ Highlights

- **Bento-grid layout** — modular cards for intro, skills, experience, and contact
- **`skills.json` card** — tech stack presented as a syntax-highlighted JSON snippet instead of a plain list
- **`git log`-style experience section** — work history rendered as commit entries (hash, author, date, message)
- **Bilingual** — full parity between Ukrainian and English content
- **Responsive** — mobile-first grid reflow

## 🎨 Design System

| Token       | Value                           |
|-------------|---------------------------------|
| Background  | `#F5F3EC` (cream)               |
| Amber       | accent color                    |
| Green       | `#C0DD97`                       |
| Blue        | `#85B7EB`                       |
| Headings    | Bricolage Grotesque             |
| Mono/code   | JetBrains Mono                  |

## 🛠 Tech Stack

- Next.js / React
- Tailwind CSS
